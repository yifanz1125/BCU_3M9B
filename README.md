# BCU_3M9B

Please ensure that **C1_Matpower** is included in the MATLAB path before running any scripts.

## network-reduction model

BCU program:  
Directly run the following script in `B3_MM`:

Cal_MM_CCT.m

Optional:  
Run the following script to plot the stability region of the reduced-order system:

Statable_Region.m

Numerical simulation and energy function:  
Run the following script:

NumSim_MM_Gridframe.m

Cal_MM_CCT_SPM.m

Optional:  
Run the following script to plot the stability region of the reduced-order system:

Statable_Region_SPM.m

Numerical simulation and energy function:  
Run the following script:

NumSim_MM_Gridframe_SPM.m
